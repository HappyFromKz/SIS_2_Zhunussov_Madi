# Toolshop — Playwright test automation (SIS 2)

E2E tests for https://practicesoftwaretesting.com/ written with Playwright + TypeScript.

- `Description.md` — goal and list of test cases
- `Prompt.md` — prompt used for the AI tool
- `Review.md` — review of AI output
- `screenshots/` — AI response and run results

```bash
npm install
npx playwright install chromium
npx playwright test
npx playwright show-report
```
